# The Number Universe

Numerology, angel numbers and real sound frequencies in one immersive site.

Static site with no build step: `index.html`, `styles.css`, `data.js`, `app.js`.

## Deploy on Render
New, then Static Site, then select this repo. Leave the build command blank and set the publish directory to `.`
Or use New, then Blueprint, and Render reads `render.yaml`.

## Content
All meanings, frequencies and intentions live in `data.js`. Every claim is labeled by lens (numerology, tradition, culture, acoustics) and frequencies carry an evidence rating.
